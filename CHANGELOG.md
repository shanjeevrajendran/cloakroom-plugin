# Changelog

## 1.0.0 (2026-10-30)

- Version 1.0.0: installs Cloakroom 1.0.0 (outgoing-data control and `cloakroom proxy`), and registers the `Stop`, `SessionEnd` and `PostToolUseFailure` events from 0.9.0.
- A small panel inside Claude Code (command `/cloakroom-panel`): shows that Cloakroom is on, this session's counts, and pause and resume buttons.
